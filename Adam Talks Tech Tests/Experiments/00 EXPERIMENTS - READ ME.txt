EXPERIMENTS (Adam, Nov 22 2026)
New test ideas live here until they're proven. They are NOT in Run This Next, the walk-away queue or the
Main Results / New Tests tabs. Results go to the "Experiments" tab of the Mac Tests sheet only.

An experiment graduates to a real test (catalog + Run Order step + its own sheet column) only after:
  1. it has run on at least 2-3 different Macs and the numbers make sense against each other,
  2. a repeat run on the same Mac lands within ~3%,
  3. Adam says it's in.
Then it runs on every Mac like the other tests.
