PUGET TEST - READ ME
Puget Bench for Creators (Puget Systems, pugetsystems.com). Press license.
Name every test in full on screen and in writing: "Puget Bench for Photoshop".

WHERE PUGET KEEPS ITS TEST FILES
  ~/Library/Application Support/com.puget.benchmark/  -> assets + benchmarks
  (Puget > Settings > Reveal Benchmark Files opens it.)
  Copy both folders to another Mac and Puget skips the downloads.

ONE TIME (any Mac with good internet)
  1. Install Puget, open it, download assets for all five benchmarks. Quit.
  2. zsh att-puget.zsh save      -> copies them to Puget Test/Assets on the LaCie

EACH TEST MAC
  1. Install PugetBench (Apps & Installers) plus the apps it tests
     (Adobe seat rules + Resolve key are in LICENSES - keep private.txt)
  2. zsh att-puget.zsh load      -> copies Assets from the LaCie into Puget
  3. zsh att-puget.zsh license   -> applies the press key (once per Mac)
  4. zsh att-puget.zsh run all   or   run "Photoshop"
     (run does step 2 by itself when this Mac is missing the files, and saves
      new files back to the plugged-in drive after a good run)
     Extended preset: PRESET=Extended zsh att-puget.zsh run "Lightroom Classic"
  Results: Results/<Mac name>/Puget/

FIRST RUN OF EACH APP ON A MAC
  macOS asks for your password (Puget installs its plugin into the app). Terminal
  can't show that box, so the run ends "No result file". Do that first run from
  the Puget app, type the password, then use Terminal from then on.
  Open every Adobe app once first (sign-in, first-launch screens), then quit.
  App runs: zsh att-puget.zsh collect  copies the CSVs to Results and the drive.

RULES
  Cool start before Lightroom. After Effects: run twice, log the 2nd.
  Resolve: Super Scale under ~5 fps = rerun. Results only upload to Puget
  if you add --upload_results (the script doesn't).
  Before a loaner ships: deactivate Resolve and sign out of Adobe.
