6. TEST RULES THAT APPLY TO EVERYTHING
--------------------------------------------------------------------------
- Same macOS on every Mac, log the version. Turn off auto updates during a batch.
- Plugged in, Low Power Mode off, cooldown (shut down or idle 15+ min) before
  Lightroom and long tests.
- Everything runs from ~/Downloads/Adam Talks Tech Tests. Use
  Tools/att-copy-tests.zsh to copy it in blocks (it logs free GB for you).
- Timed files run from the internal drive, not from this SSD (except the
  image gen kit, which is built to run from the SSD).
