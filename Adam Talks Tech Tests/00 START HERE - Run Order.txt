ATT MAC TESTS - START HERE (one Mac at a time, one test at a time)
Made Nov 20 2026. Core list = CORE TESTS - every loaner.txt. Details per test
are in each folder's READ ME. Tick the boxes as you go (copy this file per Mac
if you like).

HOW IT WORKS
  Drag the whole "Adam Talks Tech Tests" folder into ~/Downloads on the test Mac.
  Keep the folder names and nesting exactly as they are. Every script finds
  everything from where it sits, so nothing needs a drive plugged in, and the
  timed tests run off the Mac's own SSD (they refuse to run from a drive).

  Not enough space? (whole folder is about 220GB) Make the same nesting, i.e.
  ~/Downloads/Adam Talks Tech Tests/, and drag in only what you're testing.
  Always bring: _Read Me First, Tools, Results, and the folder for the test.
  Big folders: AI Tests 115GB (the models), Logic Test - Big Session 63GB,
  Final Cut Test 45GB, Apps & Installers 25GB, Lightroom Test 16GB,
  WebKit Test 7GB, HandBrake Test 6GB. On a 512GB Mac do one big one at a time.
  Tip for AI Tests: drag it WITHOUT the "LM Studio Models" folder and run
  att-models.zsh load with the drive plugged in (copies only the models you pick).

  GAMES live in their own folder at the top of the drive: "Adam Talks Tech Games"
  (Steam Library inside: Cyberpunk, War Thunder). Drag it into ~/Downloads only
  for the game tests, so they run off the Mac's internal drive (fair on every Mac),
  then delete it. It's separate because it's so big.

  INSTALL ALL THE APPS AT ONCE (new Mac):
     cd ~/Downloads/"Adam Talks Tech Tests"/"Tools" && zsh att-install-apps.zsh
  (EXTRAS=1 in front adds 3DMark, Procyon image gen, Diffusion Bee, TG Pro.)
  It opens the App Store pages for Xcode / Final Cut / Logic / Compressor and the
  Creative Cloud installer for the parts that can't be scripted.

WHERE RESULTS GO
  Every script saves into  ~/Downloads/Adam Talks Tech Tests/Results/<Mac name>/
  Nothing goes to the Desktop.
  Apps with no script (Geekbench, Cinebench, Cyberpunk, 3DMark, Procyon):
  screenshot the result screen into Results/<Mac name>/Screenshots
  (make the folder the first time). Step 99 brings the results back.

SETUP (once per Mac)
------------------------------------------------------------------
TIP: Copy each command line whole, from "cd" to the end. The cd part puts
Terminal in the right folder; without it you get "can't open input file".

[ ] 1. Plugged in, Low Power Mode off, macOS + App Store auto updates off,
       same macOS as the other Macs in the batch.
[ ] 2. Drag "Adam Talks Tech Tests" into ~/Downloads (see HOW IT WORKS above).
[ ] 2b. Get the newest scripts (every time you sit down at a Mac that already has
        the folder, and after Claude says a script was fixed):
        DOUBLE-CLICK  "Update Scripts.command"  in the test folder. That's it.
        (Same thing typed: curl -fsSL https://raw.githubusercontent.com/adamtalkstech/att-Mac-tests/main/att-update.zsh | zsh)
        Only scripts and instructions change. Results, models, games and apps stay put.
[ ] 3. Name the Mac (wallpaper + Mac name that every result uses):
         cd ~/Downloads/"Adam Talks Tech Tests"/"Tools" && zsh att-name-this-mac.zsh
[ ] 4. Version card (every test day, before the first test):
         cd ~/Downloads/"Adam Talks Tech Tests"/"Tools" && zsh att-versions.zsh
[ ] 5. Restart, quit everything, let it sit 15 min before the first test.
