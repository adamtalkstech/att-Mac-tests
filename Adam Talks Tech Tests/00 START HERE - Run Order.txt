ATT MAC TESTS - RUN ORDER  (Nov 21 2026)
Short version. Every step is ONE command: copy the whole line, paste in Terminal.
Long version with every setting and fix: _Read Me First/Run Order - full details.txt
Step numbers are the same as before, so "step 14c" still means Gemma.

==================================================================
A. SET UP THE MAC  (first time on a Mac, then just step 2b each day)
==================================================================
[ ] 1.  Plugged in (laptops: Apple's charger straight into the Mac, no dock),
        Low Power Mode off, auto updates off.
[ ] 2.  Drag "Adam Talks Tech Tests" (or a kit's copy) into Downloads.
[ ] 2b. Double-click "Update Scripts.command" in that folder. EVERY time you sit down.
[ ] 3.  Name the Mac:
          zsh ~/Downloads/"Adam Talks Tech Tests"/Tools/att-name-this-mac.zsh
[ ] 3b. Install the apps (opens App Store / Adobe pages for the ones you click):
          zsh ~/Downloads/"Adam Talks Tech Tests"/Tools/att-install-apps.zsh
[ ] 4.  Version card (each test day):
          zsh ~/Downloads/"Adam Talks Tech Tests"/Tools/att-versions.zsh

==================================================================
B. WALK-AWAY TESTS  (one command runs them all, ~2.5-3 hours)
==================================================================
[ ] QUEUE: 8 Xcode, 9 Blender, 9b Red Autumn, 10 sustained, 11 HandBrake,
           14a Qwen 9B, 14b Qwen 27B, 14c Gemma, 14d ladder (32GB+ only)
          zsh ~/Downloads/"Adam Talks Tech Tests"/Tools/att-queue.zsh
    - Type the password once. Keep a test drive plugged in for the first minute
      or two (it copies the AI models), then it says you can unplug it.
    - Already done some? Leave them out:   SKIP="xcode blender" zsh ...att-queue.zsh
      Only some?                           QUEUE="sustained gemma" zsh ...att-queue.zsh
    - Don't use the Mac while it runs. Every card lands in Results/<Mac>/Queue/.
